# Yaf 常量

由 yaf 扩展注册的常量。

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `YAF_VERSION` | `3.3.8-dev` | 扩展版本 |
| `YAF_ENVIRON` | `product` | 默认环境名 (`yaf.environ` 的编译期默认值) |
| `YAF_ERR_STARTUP_FAILED` | `512` | 启动失败 |
| `YAF_ERR_ROUTE_FAILED` | `513` | 路由失败 |
| `YAF_ERR_DISPATCH_FAILED` | `514` | 分发失败 |
| `YAF_ERR_AUTOLOAD_FAILED` | `520` | 自动加载失败 |
| `YAF_ERR_NOTFOUND_MODULE` | `515` | 模块未找到 |
| `YAF_ERR_NOTFOUND_CONTROLLER` | `516` | 控制器未找到 |
| `YAF_ERR_NOTFOUND_ACTION` | `517` | 动作未找到 |
| `YAF_ERR_NOTFOUND_VIEW` | `518` | 视图未找到 |
| `YAF_ERR_CALL_FAILED` | `519` | 调用失败 |
| `YAF_ERR_TYPE_ERROR` | `521` | 类型错误 |
| `YAF_ERR_ACCESS_ERROR` | `522` | 访问错误 |
